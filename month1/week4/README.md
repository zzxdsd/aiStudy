# 关于月1交付的agent

## 这个agent是干嘛的
- 在跟AI对话过程中，你可以一句话让AI帮你自动归档你觉得有用的知识点到你本地笔记，并且你可以根据关键词或者标签让AI帮你搜索本地笔记中相关的笔记内容

## 为什么要做这个agent
- 今年5月份，我和 AI 进行了一次五小时的长对话,聊到尾声时我意识到中间有几段内容是值得长期保存的,我下意识的想要像使用聊天软件一样去搜索对话内容，但当我试图回头找时——Claude.ai 没有定位某段对话的功能,只能 Ctrl+F 或导出整个 PDF。
- 我意识到这是一个真实的产品需求，我自己在这次五小时的咨询对话中,产生了至少三次"这段需要保存下来"的冲动。最终我用 AI 的文件工具凑合实现了一次归档,但流程繁琐、依赖运气。
- 这个项目的目的就是把这个流程做成产品级:**对话进行时一句话触发归档,内容自动分类、打标签、可被检索**

## 如何运行这个agent
- 在终端中将你的API_KEY设置到环境变量中
    - $env:DEEPSEEK_API_KEY="sk-你的key"

## 目前实现的功能
- 目前只是一个雏形，实现了save_notes和search_notes的核心功能

## 技术使用
- 用了 LLM Tool Use,模型自主决定调用工具
